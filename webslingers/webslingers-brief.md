# Webslingers.inc homepage: brief

**Goal:** Marketing homepage for Webslingers.inc — professional-looking websites for small businesses in Vietnam, fast and cheap. Visitors should want to request a quote.

**Slogan:** "From idea to live in record time."

## Design direction: "Bold Sling" (cream / red / gold)
Playful neo-brutalist: thick black borders, hard offset shadows, big chunky headings, rotated ticker strip.

| Token | Value |
|---|---|
| Background (cream) | `#fff3d1` |
| Ink | `#111111` |
| Accent (red-coral) | `#ff6a5c` |
| Highlight (gold) | `#ffcd00` |
| Cards | `#ffffff` |

- Fonts: Unbounded 700/900 (headings, buttons), Manrope 400/600/800 (body)
- Cards: 3px solid #111, 20px radius, `8px 8px 0 #111` shadow
- Primary button: #111 bg, cream text, `6px 6px 0` red shadow
- Hero: faint web-line SVG from top-right corner
- Ticker: black band, cream text, rotated -1.2deg, FAST / PRO / CHEAP / LIVE

## Sections
1. Nav — WEBSLINGERS.INC, How it works / Work / Pricing, Get a quote
2. Hero — slogan H1, subcopy, Start my website / See our work
3. Ticker
4. How we sling it — Share the idea, We build fast, Go live

8. Footer
